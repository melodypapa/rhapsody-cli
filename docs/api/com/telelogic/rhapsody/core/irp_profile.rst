IRPProfile
==========

The IRPProfile interface represents a profile extending IRPPackage.

- **Java interface:** IRPProfile
- **Java package:** com.telelogic.rhapsody.core
- **JavaDoc description:** The IRPProfile interface represents a profile extending IRPPackage. It declares no owned members.
- **Python wrapper:** IRPProfile
- **Python import:** ``from rhapsody_cli.models.com.telelogic.rhapsody.core import IRPProfile``
- **Canonical module:** ``rhapsody_cli.models.com.telelogic.rhapsody.core.irp_profile``

API reference
-------------

Wraps ``IRPProfile``: a profile extending ``IRPPackage``. The wrapper has no
public members of its own; all behavior is inherited from ``IRPPackage``,
``IRPUnit`` and ``IRPModelElement``.
