IRPRelation
===========

The ``IRPRelation`` interface is the base for relationships between classifiers.

- **Java interface:** IRPRelation
- **Java package:** ``com.telelogic.rhapsody.core``
- **JavaDoc description:** The ``IRPRelation`` interface is the base for relationships between classifiers.
- **Python wrapper:** ``IRPRelation``
- **Python import:** ``from rhapsody_cli.models.com.telelogic.rhapsody.core import IRPRelation``
- **Canonical module:** ``rhapsody_cli.models.com.telelogic.rhapsody.core.irp_relation``

API reference
-------------

``IRPRelation`` wraps a relationship model element and extends ``IRPUnit``. Accessor families declared as properties in the type library are exposed as Python properties; setters exist only where the JavaDoc declares one.
