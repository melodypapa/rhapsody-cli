IRPInstance
===========

The ``IRPInstance`` interface represents an instance in the Rhapsody model.

- **Java interface:** IRPInstance
- **Java package:** ``com.telelogic.rhapsody.core``
- **JavaDoc description:** The ``IRPInstance`` interface represents an instance in the Rhapsody model.
- **Python wrapper:** ``IRPInstance``
- **Python import:** ``from rhapsody_cli.models.com.telelogic.rhapsody.core import IRPInstance``
- **Canonical module:** ``rhapsody_cli.models.com.telelogic.rhapsody.core.irp_instance``

API reference
-------------

``IRPInstance`` wraps an instance model element and extends ``IRPRelation``. The instantiating operation getter/setter pair is exposed as the read/write Python property ``instantiated_by``.
