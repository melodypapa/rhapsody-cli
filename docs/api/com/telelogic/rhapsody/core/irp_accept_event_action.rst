IRPAcceptEventAction
====================

The IRPAcceptEventAction interface represents Accept Event Action elements in a statechart or activity diagram. To create an Accept Event Action element, use ``IRPFlowchart.addAcceptEventAction``.

- **Java interface:** IRPAcceptEventAction
- **Java package:** com.telelogic.rhapsody.core
- **JavaDoc description:** The IRPAcceptEventAction interface represents Accept Event Action elements in a statechart or activity diagram. To create an Accept Event Action element, use the method IRPFlowchart.addAcceptEventAction.
- **Python wrapper:** IRPAcceptEventAction
- **Python import:** ``from rhapsody_cli.models.com.telelogic.rhapsody.core import IRPAcceptEventAction``
- **Canonical module:** ``rhapsody_cli.models.com.telelogic.rhapsody.core.irp_accept_event_action``

API reference
-------------

The JavaDoc ``getEvent`` / ``setEvent`` pair is exposed by pywin32 as the read/write Python property ``event``.

- **Signature:** ``event: IRPEvent`` (read/write)
- **Get:** Returns the event that the action waits for.
- **Set:** Specifies the event that the action should wait for.
