IRPContextSpecification
=======================

The IRPContextSpecification interface represents the exact context of an object in a hierarchy.

- **Java interface:** IRPContextSpecification
- **Java package:** com.telelogic.rhapsody.core
- **JavaDoc description:** The IRPContextSpecification interface represents the exact context of an object in a hierarchy, using a collection of strings for the full path and a collection of indices for multiplicity disambiguation.

- **Python import:** ``from rhapsody_cli.models.com.telelogic.rhapsody.core import IRPContextSpecification``
