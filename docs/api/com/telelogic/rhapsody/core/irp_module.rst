IRPModule
=========

The ``IRPModule`` interface represents a module in the Rhapsody model.

- **Java interface:** IRPModule
- **Java package:** ``com.telelogic.rhapsody.core``
- **JavaDoc description:** The ``IRPModule`` interface represents a module in the Rhapsody model.
- **Python wrapper:** ``IRPModule``
- **Python import:** ``from rhapsody_cli.models.com.telelogic.rhapsody.core import IRPModule``
- **Canonical module:** ``rhapsody_cli.models.com.telelogic.rhapsody.core.irp_module``

API reference
-------------

``IRPModule`` extends ``IRPInstance`` and declares no members of its own. Its members are inherited from ``IRPInstance``, ``IRPRelation``, ``IRPUnit``, and ``IRPModelElement``; refer to those wrappers for the member descriptions. Modules are created with ``IRPPackage.add_module``.
