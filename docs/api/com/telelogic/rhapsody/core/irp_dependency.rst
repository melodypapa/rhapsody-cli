IRPDependency
=============

The ``IRPDependency`` interface represents a dependency relationship.

- **Java interface:** IRPDependency
- **Java package:** ``com.telelogic.rhapsody.core``
- **JavaDoc description:** The ``IRPDependency`` interface represents a dependency relationship.
- **Python wrapper:** ``IRPDependency``
- **Python import:** ``from rhapsody_cli.models.com.telelogic.rhapsody.core import IRPDependency``
- **Canonical module:** ``rhapsody_cli.models.com.telelogic.rhapsody.core.irp_dependency``

API reference
-------------

``IRPDependency`` wraps a dependency model element and extends ``IRPModelElement``. The dependent and supplier getter/setter pairs are exposed as read/write Python properties.
