IRPCollaboration
================

The IRPCollaboration interface represents a collaboration in a Rhapsody model.

- **Java interface:** IRPCollaboration
- **Java package:** com.telelogic.rhapsody.core
- **JavaDoc description:** The IRPCollaboration interface represents a collaboration in a Rhapsody model.
- **Python wrapper:** IRPCollaboration
- **Python import:** ``from rhapsody_cli.models.com.telelogic.rhapsody.core import IRPCollaboration``
- **Canonical module:** ``rhapsody_cli.models.com.telelogic.rhapsody.core.irp_collaboration``

API reference
-------------

Wraps ``IRPCollaboration``: a collaboration that extends ``IRPUnit``. JavaDoc
getters exposed by pywin32 as properties are surfaced as ``@property`` members.
