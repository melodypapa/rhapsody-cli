IRPActor
========

The ``IRPActor`` interface represents actors in Rhapsody models.

- **Java interface:** IRPActor
- **Java package:** ``com.telelogic.rhapsody.core``
- **JavaDoc description:** The ``IRPActor`` interface represents actors in Rhapsody models.

- **Canonical module:** ``rhapsody_cli.models.com.telelogic.rhapsody.core.irp_actor``

API reference
-------------
