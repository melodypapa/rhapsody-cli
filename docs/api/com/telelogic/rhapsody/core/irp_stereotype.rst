IRPStereotype
=============

The ``IRPStereotype`` interface represents stereotypes in Rhapsody models.

- **Java interface:** IRPStereotype
- **Java package:** ``com.telelogic.rhapsody.core``
- **JavaDoc description:** Represents stereotypes in Rhapsody models and extends ``IRPClassifier``.
- **Python wrapper:** ``IRPStereotype``
- **Python import:** ``from rhapsody_cli.models.com.telelogic.rhapsody.core import IRPStereotype``
- **Canonical module:** ``rhapsody_cli.models.com.telelogic.rhapsody.core.irp_stereotype``

API reference
-------------

``IRPStereotype`` wraps stereotype model elements. Its applicable metaclasses can be changed through the JavaDoc-owned add/remove methods. Python properties mirror the registered pywin32 property shape; ``is_new_term`` has a setter.
